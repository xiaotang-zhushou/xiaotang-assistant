# 小塘助手

给你的 AI 助手装上记忆 —— 把你交代过的规矩、事实、技能写成文件，干活前按类摆到桌面上，
不用每次都把整本重新讲一遍。

## 它做什么

- **写一条就永久记一条**：规矩、偏好、踩过的坑，记进去下次自己会挑出来
- **按类摆盘**：干活前把该看的（规矩 / 技能 / 记忆）分好类、一次递过去，而不是把一大堆全塞进对话
- **内置 10 个现成技能**：会议纪要 / 日报 / 待办整理 / 报价单 / 邮件回复 / 文件归类 / 周复盘 / 客户跟进 / 备份检查 / 资料速查（自己也能加）
- **账目看得见**：每件活花了多少、用了多少秒、有没有复用，面板上一眼看见
- **3D 脑子**：攒下来的东西长成一张能转、能放大、点开看的图
- **反复踩的坑会进清单**：同一个错第二次之前先被拦一下
- **解压双击就开**：不用装 Python；记忆 / 技能 / 账本全在本机，断网也能用
- **回传只发计数**：不发内容（命令行 `--telemetry show` 打出来的就是全部要发的东西）

它不替你拿主意 —— 摆好素材，拿主意的还是你本来就在用的那个 AI 助手。
